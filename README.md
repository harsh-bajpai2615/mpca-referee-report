# Referee Report

Step-by-step phone form for the MPCA Match Referee Report 2026-27. Answers are written onto the original form pages in the browser with pdf-lib, so the output keeps the prescribed format. Nothing is uploaded; drafts stay in the browser's local storage.

Live: https://harsh-bajpai2615.github.io/mpca-referee-report/

Field positions are in `spec.js`, in PDF points from the top-left of each page.

Each step shows the matching crop of the real form (`snips/`, cut from `form.pdf` at 200 dpi). Palette and type follow the Wise style on Refero Styles.
