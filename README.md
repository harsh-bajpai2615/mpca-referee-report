# Referee Report

Phone form for the MPCA Match Referee Report 2026-27. Answers are written onto the original form pages in the browser with pdf-lib, so the output keeps the prescribed format. Nothing is uploaded; drafts stay in the browser's local storage.

Live: https://harsh-bajpai2615.github.io/mpca-referee-report/

Field positions are in `spec.js`, in PDF points from the top-left of each page.
